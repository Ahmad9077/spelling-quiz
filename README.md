# Tiny Letter Quiz

A playful spelling quiz for 8-year-old learners. Each question asks the child to complete one missing sound with a small square answer tile containing one or two letters.

The quiz has a 1000-word bank with a description for every word, and it serves a fresh 20-question round each time.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
